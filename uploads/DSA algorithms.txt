1. SIMPLE TRANSPOSE (Sparse Matrix)
-----------------------------------
Algorithm Transpose(A,B)
(m,n,t) := (A(0,0), A(0,1), A(0,2))
(B(0,0), B(0,1), B(0,2)) := (n,m,t)
if t <= 0 then return
q := 1
for col := 0 to n do
  for p := 1 to t do
    if A(p,1) = col then
      (B(q,0),B(q,1),B(q,2)) := (A(p,1),A(p,0),A(p,2))
      q := q+1
Explanation: Transpose rearranges non-zero elements by swapping row and column indices.

2. FAST TRANSPOSE (Sparse Matrix)
---------------------------------
procedure FAST_TRANSPOSE(A,B)
declare S(n), T(n)
(m,n,t) := (A(0,0), A(0,1), A(0,2))
(B(0,0), B(0,1), B(0,2)) := (n,m,t)
if t <= 0 then return
for i := 0 to n do S(i) := 0
for i := 1 to t do S(A(i,1)) := S(A(i,1)) + 1
T(0) := 1
for i := 1 to n do T(i) := T(i-1) + S(i-1)
for i := 1 to t do
  j := A(i,1)
  (B(T(j),0),B(T(j),1),B(T(j),2)) := (A(i,1),A(i,0),A(i,2))
  T(j) := T(j)+1
Explanation: Uses row-count and position arrays for faster transpose.
alternate algorithm code style:
procedure FastTranspose(A, B)
{
    // A is sparse matrix in compact form
    // B will store the transpose

    int m = A[0][0];
    int n = A[0][1];
    int t = A[0][2];

    B[0][0] = n;
    B[0][1] = m;
    B[0][2] = t;

    if (t <= 0) return;

    // Step 1: Count elements in each column of A
    int S[n];
    for (int i = 0; i < n; i++)
        S[i] = 0;

    for (int i = 1; i <= t; i++)
        S[A[i][1]]++;

    // Step 2: Compute starting positions in B
    int T[n];
    T[0] = 1;
    for (int i = 1; i < n; i++)
        T[i] = T[i-1] + S[i-1];

    // Step 3: Place elements into B
    for (int i = 1; i <= t; i++)
    {
        int col = A[i][1];
        int pos = T[col];

        B[pos][0] = A[i][1];   // new row = old column
        B[pos][1] = A[i][0];   // new col = old row
        B[pos][2] = A[i][2];   // value stays same

        T[col]++; // move to next position
    }
}

3. SPARSE TO COMPACT
--------------------
Algorithm compact(A,m,n,B)
B(0,0)=m; B(0,1)=n; k=1
for i=0 to m
  for j=0 to n
    if A(i,j)!=0 then
      B(k,0)=i; B(k,1)=j; B(k,2)=A(i,j)
      k++
B(0,2)=k-1
Explanation: Converts full matrix into compact form storing only non-zero entries.

procedure AddSparse(a, b, c)
{
    if (a[0][0] != b[0][0] || a[0][1] != b[0][1]) return;

    int i=1, j=1, k=1;
    int t1=a[0][2], t2=b[0][2];
    c[0][0]=a[0][0]; c[0][1]=a[0][1];

    while(i<=t1 && j<=t2)
    {
        if (a[i][0]==b[j][0] && a[i][1]==b[j][1]) {
            int sum=a[i][2]+b[j][2];
            if(sum!=0){ c[k][0]=a[i][0]; c[k][1]=a[i][1]; c[k][2]=sum; k++; }
            i++; j++;
        }
        else if (a[i][0]<b[j][0] || (a[i][0]==b[j][0] && a[i][1]<b[j][1])) {
            c[k][0]=a[i][0]; c[k][1]=a[i][1]; c[k][2]=a[i][2]; k++; i++;
        }
        else {
            c[k][0]=b[j][0]; c[k][1]=b[j][1]; c[k][2]=b[j][2]; k++; j++;
        }
    }

    while(i<=t1) { c[k][0]=a[i][0]; c[k][1]=a[i][1]; c[k][2]=a[i][2]; k++; i++; }
    while(j<=t2) { c[k][0]=b[j][0]; c[k][1]=b[j][1]; c[k][2]=b[j][2]; k++; j++; }

    c[0][2]=k-1;
}

Explanation: Merge two compact sparse matrices by comparing row/col positions.

A ← sorted array, n ← size, key ← value
low=0, high=n-1
while(low<=high)
  mid=(low+high)/2

Explanation: Binary search halves the search space each step.

Algorithm SelectionSort(a[], n)
{
    for (i = 0; i < n-1; i++)
    {
        minpos = i;
        for (j = i+1; j < n; j++)
        {
            if (a[j] < a[minpos])
                minpos = j;
        }
        if (minpos != i)
        {
            temp = a[i];
            a[i] = a[minpos];
            a[minpos] = temp;
        }
    }
}

void insertionSort(arr[10], n)
{
    // loop through each element starting from index 1
    for (i = 1; i < n; i++)
    {
        key = arr[i];        // take current element as key
        j = i - 1;           // start comparing with previous element

        // shift elements greater than key one position ahead
        while (j >= 0 && arr[j] > key)
        {
            arr[j+1] = arr[j];
            j = j - 1;
        }

        // place key at its correct position
        arr[j+1] = key;
    }
}

void shell_sort(int A[], int n)
{
    gap = n / 2;             // initial gap is half of array size
    do
    {
        do
        {
            swapped = 0;     // flag to check if any swap happened
            for (i = 0; i < n - gap; i++)
            {
                // compare elements separated by gap
                if (A[i] > A[i+gap])
                {
                    swap(A[i], A[i+gap]); // swap if out of order
                    swapped = 1;          // mark that swap occurred
                }
            }
        } while (swapped == 1); // repeat until no swaps in this gap

    } while ((gap = gap / 2) >= 1); // reduce gap and continue
}

8. BUBBLE SORT
--------------
for i=1 to n
  for j=0 to n-i-1
    if a[j]>a[j+1] swap
Explanation: Repeatedly swaps adjacent elements, largest bubbles to end.

9. SELECTION SORT
-----------------
for i=0 to n-2
  minpos=i
  for j=i+1 to n-1
    if a[j]<a[minpos] minpos=j
  swap a[i],a[minpos]
Explanation: Selects minimum element each pass and places it at correct position.

10. INSERTION SORT
------------------
for i=1 to n-1
  key=arr[i]; j=i-1
  while(j>=0 && arr[j]>key)
    arr[j+1]=arr[j]; j--
  arr[j+1]=key
Explanation: Builds sorted array by inserting each element into its correct place.

11. SHELL SORT
--------------
gap=n/2
do
  do
    swapped=0
    for i=0 to n-gap-1
      if A[i]>A[i+gap] swap, swapped=1
  while(swapped==1)
while((gap=gap/2)>=1)
Explanation: Generalization of insertion sort using gaps; reduces disorder quickly.

NOTES ON SORTING:
- Bubble Sort: O(n^2), simple but slow.
- Selection Sort: O(n^2), fewer swaps, good for small arrays.
- Insertion Sort: O(n^2), efficient for nearly sorted data.
- Shell Sort: O(n log n) average, faster due to gap-based comparisons.
