Theory
1. CMP Instruction

CMP compares two operands by internally performing subtraction:

CMP destination, source

It does not store the subtraction result; only the flags are affected.

Example:

CMP AL, BL

If AL < BL, the Carry Flag is set for an unsigned comparison.

2. XCHG Instruction

XCHG exchanges the contents of two operands.

Example:

XCHG AL, BL

If:

AL = 25H
BL = 10H

After XCHG:

AL = 10H
BL = 25H

It is useful in sorting for swapping two numbers.

3. CMPXCHG Instruction

CMPXCHG means Compare and Exchange.

It compares the destination operand with the accumulator. If they are equal, the source is transferred to the destination; otherwise, the destination is loaded into the accumulator.

Example:

CMPXCHG BL, CL

It is mainly used for conditional exchange and synchronization operations.

4. BSWAP Instruction

BSWAP reverses the byte order of a 32-bit or 64-bit register.

Example:

MOV EAX, 12345678H
BSWAP EAX

Result:

EAX = 78563412H

It is useful for changing byte order/endian representation.

Algorithm
i) Algorithm for Sorting Numbers
Start.
Initialize the array and number of elements.
Set the outer loop counter.
Compare adjacent elements using CMP.
For ascending order, if the first element is greater than the second, exchange them.
Continue comparing adjacent elements.
Repeat the passes until the complete array is sorted.
For descending order, exchange the elements when the first element is smaller than the second.
Stop.
Simple Bubble Sort Logic
Compare A[j] and A[j+1]

Ascending:
If A[j] > A[j+1]
    Swap

Descending:
If A[j] < A[j+1]
    Swap
ii) Algorithm for Displaying Sorted Numbers
Start.
Load the sorted array element.
Copy the element to a register.
Extract the upper nibble using ROL and AND 0FH.
Convert the nibble to ASCII:
0–9 → add 30H
A–F → add 37H
Extract the lower nibble.
Convert it to ASCII using the same method.
Display both ASCII characters using the write system call.
Repeat for every array element.
Stop.

2. Explain ROL, AND, CMP, JBE, JNZ
ROL — Rotate Left

Rotates bits to the left. The bit shifted out from MSB enters the LSB.

ROL AL, 4

Example:

AL = 25H
ROL AL,4 → 52H
AND — Logical AND

Performs bit-by-bit AND operation.

AND AL, 0FH

Used to extract the lower nibble.

Example:

AL = A5H
AND AL, 0FH
AL = 05H
CMP — Compare

Compares two operands by subtraction and updates flags.

CMP AL, BL

The result is not stored.

JBE — Jump Below or Equal

Jumps when the first unsigned operand is below or equal to the second.

It mainly checks:

CF = 1 OR ZF = 1
JNZ — Jump if Not Zero

Jumps when:

ZF = 0

It is commonly used to repeat a loop until a value becomes zero.

3. What are different sorting algorithms and which one is better?

Common sorting algorithms:

Bubble Sort
Selection Sort
Insertion Sort
Merge Sort
Quick Sort
Heap Sort

For this practical, Bubble Sort is simple to implement in assembly because it mainly requires:

CMP → conditional jump → XCHG

For large datasets, Quick Sort/Merge Sort generally provide better average performance than Bubble Sort.
